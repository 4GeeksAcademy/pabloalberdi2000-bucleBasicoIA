🔄 ARQUITECTURA DEL BUCLE AGENTICO:

   ┌──────────────────────┐
   │ 1. OBSERVAR          │ ← Input del usuario
   └──────────┬───────────┘
              │
   ┌──────────▼───────────┐
   │ 2. PENSAR            │ → LLM (con tools definitions)
   └──────────┬───────────┘
              │
         ¿Tool calls?
         ├─SÍ───────────┐
         │              │
   ┌─────▼────┐    ┌────▼────────────┐
   │ 3. ACTUAR │    │ Ir al paso 6    │
   │(HTTP call)│    │(sin herramientas)
   └─────┬────┘    └────────────────┘
         │
   ┌─────▼─────────────┐
   │ 4. ACTUALIZAR     │ → Inyectar resultados en historial
   └─────┬─────────────┘
         │
   ┌─────▼─────────────┐
   │ 5. REPETIR        │ → Llamar LLM otra vez
   └─────┬─────────────┘
         │
   ┌─────▼──────────────────┐
   │ 6. IMPRIMIR            │ → Respuesta final + Log
   └─────┬──────────────────┘
         │
         └──→ ¿Continuar? → Volver a 1

🛠️ TECNOLOGÍAS CLAVE:

Frontend:
  • CLI interactiva (input/print en terminal)

Backend API:
  • FastAPI (framework minimalista, rápido)
  • CSV para persistencia (simple, sin BD)
  • Locks para operaciones atómicas

Agente IA:
  • Python puro (sin frameworks de agentes)
  • Anthropic Claude o OpenAI (configurable)
  • Function calling manual (definiciones en JSON Schema)
  • httpx para HTTP calls

Logging:
  • CSV append-only (cada evento una fila)
  • Inmediato (sin buffer)


🚀 INICIO RÁPIDO:
